# Drone delivery research website

This public repository contains the website for the adaptive neighborhood exposure regulation drone delivery project.

The website presents the system map, agent-based model design, pilot controls, experiment plan, and interactive prototypes. Prototype v0.19 adds the Phase E8 workload-aware planner across 13,440 event runs and quantifies its reliability-throughput tradeoff. Research development files and raw datasets remain outside this public repository.

Website: https://wychoffian.github.io/drone-delivery-research/
