# Drone delivery research website

This public repository contains the website for the adaptive neighborhood exposure regulation drone delivery project.

The website presents the system map, agent-based model design, pilot controls, experiment plan, and interactive prototypes. Prototype v0.11 adds the calibrated Phase E0 single-event acoustic module, its validation boundary, and the next route-integration contract. Research development files and raw datasets remain outside this public repository.

Website: https://wychoffian.github.io/drone-delivery-research/
