# Drone delivery research website

This public repository contains the website for the adaptive neighborhood exposure regulation drone delivery project.

The website presents the system map, agent-based model design, pilot controls, experiment plan, and interactive prototypes. Prototype v0.12 adds Phase E1 moving-route acoustic integration across nine neighborhood receivers in synthetic physical geometry. Research development files and raw datasets remain outside this public repository.

Website: https://wychoffian.github.io/drone-delivery-research/
