# Drone delivery research website

This public repository contains the website for the adaptive neighborhood exposure regulation drone delivery project.

The website presents the system map, agent-based model design, pilot controls, experiment plan, and interactive prototypes. Prototype v0.13 adds Phase E2 fleet and policy integration with physical energy reservations and declared reference-mission budget scenarios. Research development files and raw datasets remain outside this public repository.

Website: https://wychoffian.github.io/drone-delivery-research/
